#Trust No Pigeon

**Trust No Pigeon** is a 3D First-Person Action Survival Game developed in **Godot 4.7**.

Developed by **எறுழுரு (Eruzhuru Studios)**.

---

## 🎮 Game Overview

In a world where pigeons aren't what they seem, you must defend yourself against hostile government surveillance pigeons, intercept supply drones, and survive the terrifying multi-state **Boss UFO**!

### Core Features
- **FPS Marksmanship & Weaponry**: Gun (pistol), Shotgun, and Guided Missile Launcher with crosshair homing guidance.
- **Dynamic Day / Night Cycle**: Seamless 3D sky transitions (`DAY` $\to$ `SUNSET` $\to$ `NIGHT` $\to$ `DAWN`).
- **Boss UFO Encounter**: Multi-state boss featuring a holographic energy shield shader (`ufo_shield.gdshader`), hatch opening, pigeon spawning, and dynamic vulnerability windows.
- **Full UI & Audio Systems**:
  - Intro Video & Title Card Sequence (`game_title_screen.png` + `Piegon_sound.mp3`).
  - Main Menu, Settings Panel, Pause Menu, and Restart Confirmation modal.
  - Music Mixer playlist shuffler (`MusicManager`).
  - Dynamic Game Over theme music based on performance (`Game_over_2.mp3` vs `GAME_OVER.mp3`).
- **Developer Debug Suite**: Backquote (`` ` ``) & `F1` key overlay for instant testing.

## 🛠 Engine Version & Requirements

- **Engine**: Godot Engine v4.7 Stable (Forward Plus Renderer)
- **OS**: Windows / Linux / macOS
- **Main Scene**: `res://Splashscreen.tscn`

---

## 🚀 Quick Setup & Run

1. Open **Godot Engine 4.7**.
2. Click **Import** and select the `project.godot` file in this directory.
3. Press **F5** or click **Play** to run the game starting from the intro sequence.
